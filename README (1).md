# EDU AI — Smart Study & Productivity Assistant

**EDU AI** is a Streamlit web app inspired by the supplied reference design. Its friendly assistant is named **ALI**. It brings common study and productivity tools into one dashboard.

## Features

- **Assignments Maker:** create a structured assignment and download Word or PDF.
- **Docs Maker:** draft reports, formal letters, meeting minutes, notes, lesson plans, proposals, and more.
- **PDF Maker:** enter or improve content and export a PDF.
- **Excel Maker:** create an Excel workbook from a sample table or pasted CSV.
- **Chat with ALI:** ask questions and get explanations.
- **Send Email:** draft emails with ALI; optional SMTP sending after review and explicit confirmation.
- **History:** locally store generated results in SQLite and review or clear saved activity.
- **Settings:** check API status and view setup instructions.
- **Demo mode:** the interface remains usable without an API key. Demo responses are illustrative, not generated by a live AI model.

## Run locally

Recommended: Python 3.11 or 3.12.

```bash
python -m venv .venv
```

Activate the environment:

**Windows**
```powershell
.venv\Scripts\activate
```

**macOS / Linux**
```bash
source .venv/bin/activate
```

Install packages and run:

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Enable OpenAI API mode

Create `.streamlit/secrets.toml` locally:

```toml
OPENAI_API_KEY = "your-api-key"
OPENAI_MODEL = "gpt-4o-mini"
```

Restart Streamlit after changing secrets. Never commit `secrets.toml` or expose API keys in screenshots or source code.

For Streamlit Community Cloud:
1. Push `app.py`, `requirements.txt`, `README.md`, and `.gitignore` to a new GitHub repository.
2. In Streamlit Community Cloud, create a new app and select the repository and `app.py`.
3. Open the deployed app's **Settings → Secrets**.
4. Add `OPENAI_API_KEY` and `OPENAI_MODEL` in TOML format.
5. Save and reboot the app.

The app falls back to a clearly labeled demo response if no key is configured or if the API call fails. API availability, model access, and billing are controlled by the account/provider.

## Optional SMTP email sending

The email page drafts a message first. To enable actual sending, add SMTP settings to Streamlit Secrets:

```toml
SMTP_HOST = "smtp.example.com"
SMTP_PORT = 587
SMTP_USER = "your-email@example.com"
SMTP_PASSWORD = "your-provider-app-password"
```

Use your email provider's supported SMTP endpoint and app password. Review recipient, subject, and content before confirming send. Do not use this feature for unsolicited bulk email.

## Privacy and limitations

- Avoid entering confidential, sensitive, or student-identifying data unless you have authorization and an appropriate privacy basis.
- When API mode is active, prompts and relevant content are sent to the configured AI provider to generate a response.
- SQLite history is local to the running environment. On hosted platforms, local files may be ephemeral and may not persist through restarts or redeployments.
- Generated work should be reviewed for factual accuracy, citations, calculations, and academic integrity.
- PDF export uses ReportLab's default fonts. For Urdu or other right-to-left scripts, configure and embed a suitable Unicode font and RTL shaping support before relying on PDF output.

## Troubleshooting

**App starts in Demo mode**
- Check that `OPENAI_API_KEY` is present in Streamlit Secrets and has no accidental spaces.
- Check that the key has access to the configured model.
- Review app logs for API errors.

**Excel download fails**
- Confirm `openpyxl` installed successfully and redeploy.

**Email fails**
- Confirm SMTP host, port, username, app password, and provider SMTP policy. Many providers require TLS and an app password.
